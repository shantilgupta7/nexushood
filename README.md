# nexushood
society management system designed to bring transparency and ease to residential communities.

Key Features

For Administrators:
 * Complete member and flat management.
 * Centralized tracking of maintenance payments and society expenses.
 * Complaint handling and resolution management.

For Residents:
 * Simple and secure maintenance payments through the website.
 * Real-time tracking of personal contributions and awareness of where funds are utilized.
 * Easy to use complaint submission with notification updates upon resolution.
 * Quick payments for sudden society contributions.

Technologies Used
 * Frontend: HTML, CSS, JAVASCRIPT
 * Backend: PHP
 * Database: SQL
